# 🚀 Featured Projects

- **AgriTwin**: A real-time Digital Twin framework for precision farming. ESP32 sensors push telemetry via MQTT to a Raspberry Pi hub and FastAPI cloud backend for automated irrigation.
- **FlowVision**: Smart Water Digital Twin system utilizing ML-based anomaly detection algorithms and physical flow constraints to find pipe leaks. Live on Streamlit.
- **PazhamAI**: A hilarious, vision-based AI banana ripeness analyzer using the Groq Vision API, wrapped in a FastAPI backend with Malayalam roast feedback.
- **Nova Strike**: A bare-metal embedded arcade game running entirely on an ESP32-S3, featuring procedural enemy waves and particle effects.
- **ESP8266 LED Cube**: A WiFi-controlled 4×4×4 LED cube with a custom LittleFS web UI, WebSocket control, and a Three.js 3D browser simulator.
- **WireClaw**: A modular C++ robotics control framework built with PlatformIO for scalable actuator abstraction.
